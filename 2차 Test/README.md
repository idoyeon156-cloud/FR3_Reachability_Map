# fr3_link0 기반 reachability map 생성 테스트 2차
## 기본 설명
관절각 10만개를 무작위로 샘플링 한 뒤, 각 관절각에 대해 FK 를 계산해서 얻은 fr3_link0 (베이스) 기준 엔드이펙터의 도달 위치를 5cm 격자로 병합.
* 각각의 점 : 엔드이펙터 도달한 5cm 위치 격자
* 빨간색 포인트: fr3_link0의 원점 (0,0,0). 즉 베이스위치
* X, Y, Z: fr3_link0 기준거리(m)
* 밝은 점: 해당 격자에 도달한 관절 state가 상대적으로 많음
* 어두운 점: 해당 격자에 도달한 관절 state가 상대적으로 적음

## 참고사항
현재 결과가 최종적인 안전한 파지 영역은 아님. 순수하게 FK 만 적용해서 구한 workspace 모델
* 바닥 (무빙데스크) 충돌
* 불안정 자세
* 로봇의자기충돌
* 그리퍼 방향
등은 고려되지 않은 map 입니다.
특히 Z<0인 구간은 베이스보다 엔드이펙터가 더 밑으로 내려갈 수 있다는 것인데, 무빙데스크 위에 베이스가 올라가므로 Z<0 구간은 실질적인 도달 가능구간이 아닙니다.(즉 사용불가)
